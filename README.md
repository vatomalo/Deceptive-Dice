Deceptive Dice

A cinematic dice-duel micro-JRPG built in pure JavaScript/Canvas.
Inspired by Seiken Densetsu 3, Samurai Shodown, and FFVII’s materia system.

🎲 Roll → Clash → Attack or Pass.
Every round is a mind game.

🔗 Play here:
https://vatomalo.github.io/Deceptive-Dice/

Core Systems

Dice Combat Engine
Custom 3×2 sprite dice with physics bounce, wobble, smoke concealment, and dramatic reveal.

Character Animation System
State-based sprite sheets (idle/run/attack/hurt/death), tween movement, blink-teleport PASS effects.

Enemy Progression
Four knight tiers with scaling STR/AGI/DEF, Souls-style titles, and randomized enemy materia.

Materia System
Counter, Thorns, Poison, Speed, Barrier, Regen, Crit — fully integrated into combat.

Stamina System
Light fighting-game stamina for player and enemy, with regen and action costs.

Living World FX
Parallax layers, Neo-Geo-style decor buffers, sakura & rain weather, dynamic day/night palettes.

Combat FX + UI
Particles, slashes, sparks, smoke, adaptive BGM, announcer cues, HP bars, and X-Bar controls.

Tech

ES6 JavaScript

HTML5 Canvas

Zero libraries

Fully custom engines (animation, physics, FX, combat)

Vision

An arcade-intense duel system wrapped in JRPG depth —
where every roll feels decisive and every clash is cinematic.
